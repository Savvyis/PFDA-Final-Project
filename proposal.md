# PFDA-Final-Project
# Etch-a-Sketch Game

## Repository
<https://github.com/Savvyis/PFDA-Final-Project>

## Description
The program will open a window where the user can use the arrow keys to draw on an etch-a-sketch.
This is relevant to digital arts because it creates a fun and simple way to create digital drawings.

## Features
- Drawing Feature
	- The user will be able to use the arrow keys on a keyboard to draw lines within a specified area
- Shake Feature
	- The user will be able to press a button that "shakes" the etch-a-sketch to clear the screen
- Diagonal Drawing Feature 
	- Being able to press a horizontal and vertical key at the same time to get a diagonal line

## Challenges
- I will need to figure out how to allow the user to use the arrow keys to create lines, and stop when they release the arrow key
- I will need to restrict the area that the user can draw in so it looks like the user is only drawing within an etch-a-sketch screen
- I will have to create a button that can be activated by a click or a key press to clear the screen
- I would like for the screen to actually shake when the screen is cleared

## Outcomes
Ideal Outcome:
- Ideally the program will open a window that shows an image of an etch-a-sketch with some border areas around it that contain the shake button and some brief instruction on how to use the program (explaining what each arrow key does). The arrow keys will be able to draw up, down, left, right, and diagonally within the drawing space of the etch-a-sketch. There will be a shake button that will make the etch-a-sketch shake and clear the screen, ready for the next drawing. 

Minimal Viable Outcome:
- The program will open a screen that can be drawn on using the arrow keys. It will also need a way to also erase what is on the screen.
